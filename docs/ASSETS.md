
## 3. 能力矩阵（已实测）

| 动作 | 能否 | 做法 / 限制 |
|---|---|---|
| 呼吸起伏 | ✅ | 身体 scaleY 1.0→1.015 + 位移 |
| 左右轻晃 | ✅ | 整体旋转 ±2° |
| 头部小幅转动 | ✅ | 脸组平移 ±16px 无破绽；±40px 开始露馅（发/脸不联动） |
| 眨眼 | ✅ **效果好** | 隐藏眼白+虹膜，睫毛下移 22–26px → 呈现「笑眼」。已验证 |
| 说话口型 | ✅ 程序化近似 | 嘴层含肤色填充，不能直接缩放；现已用「嘴洞叠加 + 擦线补丁」或压扁嘴层做开合；元气皮肤张嘴时把 w 闭嘴边整层收掉，再淡入画好的张开嘴。见 `docs/SKIN-SPEC.md` |
| 视线跟随鼠标 | ⚠️ 小幅度 | 虹膜 ±3px 内自然，再大就出眼白 |
| 拖拽形变 | ✅ | 弹簧缩放 + 头发/鳍滞后 |
| 挥手 / 走路 / 坐下 | ❌ | 只有 1 个姿势，手臂在衣服层里、且被裁断 |
| 大笑 / 生气 / 哭 / 困 | ❌ | 无表情差分；只能靠眉毛位移 + 气泡符号贴纸 |
| 鱼鳍摆动 | ⚠️ | 需先从 08 层拆出左右鳍 |

## 4. 缺口清单

**P0（不补也能上线，补了明显更好）**
1. 手绘张嘴 2 档（小张/大张）+ 笑嘴 —— 现在有程序化开合兜底，但手绘差分能做出牙齿/舌头细节，情绪也更丰富
2. 左右鱼鳍拆层（我可以程序化拆，边缘手工修一点）

**P1（情绪表达）**
3. 闭眼已有替代方案，但「困」「生气」「哭」「害羞」需要：泪滴、井字符、腮红加强、zzz
4. 2–3 个姿势差分：挥手、托腮、趴

**P2（长期）**
5. 头发分束（左右侧发、呆毛独立）→ 摆动更活
6. 半身/全身走路姿势 → 桌面游走

## 5. 交付规格（第 2–4 个角色照此办理）

- 画布 **正方形，1024 或 2048**，所有层严格同尺寸、同位置（不要各自裁边）
- 透明底 PNG，**不要**把背景/参考图混进层里
- 层名统一：`body / topwear / bottomwear / neck / arm-l / arm-r / hand-l / hand-r / headwear / face / nose / mouth / eyewhite-l/r / irides-l/r / eyelash-l/r / eyebrow-l/r / hair-front / hair-back / fin-l / fin-r`
- 眼睛、嘴、眉毛、发、鳍**必须独立**；手臂尽量从衣服层里分出来
- 每个角色附：6–8 个表情差分（可用「局部补丁 PNG」而不是整图重画）
- 若出自 AI 服务，附上该服务的商用条款说明（开源要写清授权）
